# LaunchProof — Evidence-Based Hardware GTM Decision Studio

智能硬件海外上市证据与策略决策工作台 · **公开预览 / 持续完善中**

帮助研究者解释“为什么作出这一项GTM研究选择”：把官方资料、准确型号、购买障碍假设、营销信息和决策理由串成可追溯的工作流程。

这是一项AI辅助开发的个人作品集原型，不是企业上市项目或经过真实市场效果验证的产品。技术检查与个人业务验收分开记录；个人来源、英文语义、方案选择及V1最终业务验收仍待完成。当前未进入LP05或V2。

## 业务问题与工作流

同一句“智能窗帘自动化”可能隐藏杆型、安装结构、地区和生态设备要求。营销信息需要解释这些条件，不能将通用品类资料当成特定型号承诺。

**研究任务 → 官方证据 → 竞品比较 → 未验证购买障碍假设 → 中英文信息方案A/B → 方案选择、反证与后续验证 → 可追溯简报。**

- 比较美国市场的 **SwitchBot Curtain 3 Rod Type 1** 与 **Aqara Curtain Driver E1 Rod Version**；不混用其他地区或型号。
- 初始8条事实、7条来源和6个比较维度。证据评估日为 **2026-10-24**，上线不代表重新核验了官网资料。
- 3条用户假设与2套中英文信息草案由操作者主动载入；均明确标记未验证/AI辅助草案，实际研究样本0。
- 购买障碍权重及敏感性分析是设计假设，不是消费者需求、转化率或销量数据。
- 上游证据变化会触发下游复核；历史版本保留。不能凭来源存在就判定营销结论成立。
- 保存研究倾向、暂缓选择、选择理由、反证、风险和后续验证。研究选择不等于对外发布批准。
- 导出中文、英文或双语Markdown草稿以及JSON备份。历史审核导入后，不自动证明当前用途成立。

没有真实销量、市场份额、渠道成本或投放效果数据；不提供V2供需预算模型、真实消费者评价抓取、后台账户或付费API。

## 特别保留的未知与限制

F005的相关资料仍待核实；F006保留历史/时效限制；F007通用资料不能直接证明Type 1专用规格。字段完整不等于英文语义已经人工审核。英文自由文本不自动翻译；草稿会披露缺项。

一次只打开一个研究任务，通过JSON切换。数据保存在当前浏览器中，换设备不会同步；替换前请导出需要长期保留的副本。请不要输入个人隐私或企业内部资料。本仓库不包含作者简历、私人练习数据、电脑路径或原始私人开发历史。

## 本地运行

环境要求：Node.js 24.x、pnpm 11.25.0。下载或克隆本仓库，在仓库根目录打开PowerShell：

```powershell
.\run.ps1 install
.\run.ps1 dev
```

打开 `http://127.0.0.1:5173/`。脚本优先使用本机Node/pnpm，也支持Codex已配置的运行环境。普通开发环境也可进入`app`后运行：

```text
pnpm install --frozen-lockfile
pnpm run dev
pnpm run typecheck
pnpm test
pnpm run check:data
pnpm run build
```

`check:data`是全部单元测试中的种子检查子集，不另加为独立测试总量。

## 代码结构

| 路径 | 作用 |
|---|---|
| `app/src/domain/` | 数据结构、引用、证据、评分、信息审核、决策规则 |
| `app/src/application/` | 编辑命令、状态协调、简报生成 |
| `app/src/infrastructure/` | 本地保存、导入导出、练习隔离 |
| `app/src/features/` | 任务、证据、比较、研究、决策、简报界面 |
| `app/tests/unit/` | 业务规则及回归测试 |
| `examples/research-start.json` | AI准备的公开练习夹具，个人选择与核查为空 |
| `docs/` | 由当前源码生成的静态演示产物，供GitHub Pages发布 |
| `verification/` | 本次发布真实执行结果 |

公开副本采用单独的初始提交，未重建或冒充历史里程碑提交。后续以真实变更记录迭代。
